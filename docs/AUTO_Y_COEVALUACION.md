# Plantilla de autoevaluación y coevaluación

Cada criterio vale 1 punto **solo si se acompaña de evidencia concreta** (tarea Kanban, commit, Pull Request, archivo, funcionalidad o problema resuelto). Completar individualmente y con datos reales.

## Autoevaluación (5 puntos)

| Criterio | Evidencia (tarea Kanban / commit / PR / archivo) | Puntaje (0–1) |
|---|---|---|
| **Cumplimiento** — Cumplí las tareas comprometidas y puedo demostrarlo. | | |
| **Aporte técnico** — Realicé aportes relevantes en frontend y backend. | | |
| **Git/GitHub** — Utilicé mi rama, commits y Pull Requests de forma correcta. | | |
| **Trabajo colaborativo** — Participé en integración, revisión y resolución de problemas. | | |
| **Comprensión** — Comprendo el sistema completo y puedo explicar mis decisiones y código. | | |

## Coevaluación (5 puntos) — Compañero/a evaluado/a: ________________

| Criterio | Evidencia verificable | Puntaje (0–1) |
|---|---|---|
| **Responsabilidad** — Cumplió las tareas y acuerdos definidos. | | |
| **Aporte técnico** — Realizó aportes relevantes y verificables. | | |
| **Git/GitHub** — Trabajo real y ordenado en su rama; participó en Pull Requests. | | |
| **Colaboración** — Participó en integración, pruebas y resolución de problemas. | | |
| **Comprensión y comunicación** — Explicó sus avances, decisiones y dificultades. | | |
